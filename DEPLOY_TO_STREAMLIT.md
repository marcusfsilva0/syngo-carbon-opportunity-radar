# Publish the syngo Carbon Opportunity Radar

This creates a live Streamlit Community Cloud URL for the MBA working-artifact submission.

## Before publishing

- Review the app and confirm you are allowed to publish the product positioning and examples in a public or externally accessible app.
- Do not upload confidential Siemens information, internal customer data, or API keys.
- The app can be demonstrated without a SAM.gov API key using its Google News RSS search and its separate labelled RFP/RFI evaluation cases. Direct SAM.gov database search requires the user to enter their own SAM.gov public API key in the app sidebar. OpenAI assessment is optional.

## Step 1 — Create a GitHub repository

1. Sign in to GitHub.
2. Create a new repository named `syngo-carbon-opportunity-radar`.
3. Choose **Private** if your instructor can access it and the assignment allows private repository access; otherwise use a public repository only after confirming that the code and product materials may be shared publicly.
4. Keep the default branch name `main`.
5. Upload all files in this folder to the **root** of the repository. In particular, `app.py` and `requirements.txt` must be at the top level, not inside another subfolder.
6. Commit the files.

You can upload the files in the GitHub website using **Add file → Upload files**, or use Git:

```bash
git init
git add .
git commit -m "Initial syngo Carbon Opportunity Radar MVP"
git branch -M main
git remote add origin https://github.com/YOUR-GITHUB-USERNAME/syngo-carbon-opportunity-radar.git
git push -u origin main
```

Replace `YOUR-GITHUB-USERNAME` with your GitHub username.

## Step 2 — Deploy on Streamlit Community Cloud

1. Open https://share.streamlit.io/ and sign in with GitHub.
2. Authorize Streamlit Community Cloud to access the repository. If the repository is private, authorize private-repository access in Streamlit settings.
3. Select **Create app**.
4. Select the repository `syngo-carbon-opportunity-radar`, branch `main`, and main file path `app.py`.
5. Optionally choose an app subdomain, such as `syngo-carbon-opportunity-radar` (availability is determined by Streamlit).
6. Select **Deploy** and wait for the build to complete.
7. Copy the generated `https://<your-chosen-name>.streamlit.app` address and test it in a private/incognito browser window.

Official instructions: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

## Step 3 — Test the deployed artifact

- Open the app using the generated URL in a private/incognito browser window.
- Confirm the dashboard loads without a traceback.
- Open **RFP examples & evaluation cases** and check that the VA solicitation and expired New Jersey RFI are both displayed with their respective statuses.
- Run a public-news scan without API keys and confirm that the UI handles empty or limited search results gracefully.
- If you have a SAM.gov API key, enter it in the sidebar and confirm federal procurement retrieval. Do not put the key in the Git repository or in this README.
- Confirm the CSV download works.

## Data and credential note

The SAM.gov connector is optional and uses a key typed into the app at runtime. Each person using the deployed app needs to supply their own key for direct SAM.gov search. The OpenAI second-pass assessment is also optional. No keys should be committed to GitHub. If the app is publicly accessible, avoid embedding personal API keys as shared server secrets unless you have designed appropriate access controls and usage limits.

## What to submit

- The live URL generated by Streamlit Community Cloud.
- The GitHub repository URL, if permitted by your instructor.
- The one-page specification and evaluation note as separate assignment documents.
- The three-minute walkthrough video and honest build account.

A ZIP file alone is not the live URL; it is the source package used to create the repository and deployment.
